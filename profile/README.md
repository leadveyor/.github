# Leadveyor

**AI lead scoring for service businesses and agencies.** Leadveyor reads every enquiry (emails, web forms, CRM conversations, any text), filters junk, extracts who the customer is and what they want, and scores each lead by *your* criteria, with the reason and evidence for every point.

[Website](https://leadveyor.com) · [Docs](https://leadveyor.com/docs) · [API reference](https://leadveyor.com/docs/api) · [Console](https://console.leadveyor.com)

## Official SDKs

| Language | Install | Source |
|---|---|---|
| TypeScript / JavaScript | `npm install @leadveyor/sdk` | [npm](https://www.npmjs.com/package/@leadveyor/sdk) |
| Python | `pip install leadveyor` | [leadveyor-python](https://github.com/leadveyor/leadveyor-python) |
| PHP | `composer require leadveyor/leadveyor-php` | [leadveyor-php](https://github.com/leadveyor/leadveyor-php) |

Every SDK covers the whole REST API, with pagination, retries, typed errors and webhook signature verification.

## Connect it to your stack

- **CRMs:** [GoHighLevel](https://leadveyor.com/docs/integrations/gohighlevel), [HubSpot](https://leadveyor.com/docs/integrations/hubspot), [Pipedrive](https://leadveyor.com/docs/integrations/pipedrive)
